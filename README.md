## 👩‍💻 About Me

- Java / Spring Boot를 중심으로 REST API와 웹 백엔드 서비스를 구현합니다.
- 기능 단위 구현뿐 아니라 도메인의 상태와 전체 서비스 흐름을 고려해 설계하려고 합니다.
- 재고·결제와 같은 데이터 처리에서 동시성과 정합성, 실패 상황​을 고려한 경험이 있습니다.
- Spring Security를 활용해 인증·인가와 역할 기반 접근 제어를 구현했습니다.
- 구현 결과를 추측으로 판단하기보다, 테스트와 로그를 통해 직접 검증하는 것을 중요하게 생각합니다.
- React와 외부 API를 활용한 웹 구현부터 Docker·Nginx·AWS EC2를 이용한 배포까지 경험했습니다.
